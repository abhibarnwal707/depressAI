# Pre-Trained Models

This directory contains the implementation for using pre-trained models for depression prediction.

## Models

- `rafalposwiata/roberta-large-depression`
- `rafalposwiata/deproberta-large-depression`

## Methodology

- These models classify text into not depression, moderate, and severe.
- Models are available on the Hugging Face Transformers library.

## Files

- `usage_pretrained_models.ipynb`: Notebook for using the pre-trained models.

## Impact

Allows for quick deployment of depression prediction models with interpretability using SHAP analysis.
