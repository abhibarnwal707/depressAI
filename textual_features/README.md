# Textual Features

This directory contains the methodology and implementation for extracting and modeling textual features for depression prediction.

## Files

- `textual_features.ipynb`: Notebook for extracting textual features.
- `textual_modeling.ipynb`: Notebook for training different machine learning models on textual features.
- `trained_model.pt`: Trained machine learning model.

## Impact

Provides insights into depression through textual analysis, forming the basis for further multimodal analysis.
